# 示例工程

本目录存放可运行的示例工程（clone 即跑），帮助开发者快速上手 AgentStudio API 调用。

## 示例列表

| 示例 | 说明 |
|------|------|
| [quick-chat](quick-chat/) | 通过 REST API 调用已发布的智能体，发送问题并接收回复 |

## 约定

每个示例独立子目录，包含：

- `README.md` — 示例说明、运行命令与预期输出
- 相关脚本或配置文件

新增示例请确保 clone 后可按 README 步骤直接运行。入门指引参见 [快速启动](../docs/zh/tutorial/01-quick-start.md) 与 [用户指南](../docs/zh/tutorial/02-user-guide.md)。
