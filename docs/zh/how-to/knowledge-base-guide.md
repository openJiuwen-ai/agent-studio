# 知识库接入指南

## 1. 知识库介绍

知识库通过检索增强生成（RAG）技术，为智能体提供企业私有知识检索能力。支持对文本文档、FAQ 等数据进行向量化存储和语义检索，使智能体回答有据可查。

**核心能力：**
- 支持多种文档格式（docx、pdf、pptx、xlsx、csv、txt、md 等）
- 支持知识文档和 FAQ 问答对两种数据形态
- 支持向量化存储与语义检索
- 可为应用、工作流提供检索增强能力

---

## 2. 知识库分类

| 类型 | 文档管理 | 数据存储 | 适用场景 |
|------|---------|----------|----------|
| **平台知识库** | 支持：创建、上传文档、解析、向量化、检索全流程管理 | 平台内 | 无现成知识库，需上传文档管理 |
| **第三方知识库** | 不支持：仅做检索对接，文档由第三方系统管理 | 第三方系统 | 已有企业知识库，希望直接对接 |

**第三方知识库支持类型：**

| 类型 | 说明 |
|------|------|
| General | 通用外部知识库，需按接入规范适配 |
| KooSearch | 直接接入 KooSearch 知识库 |
| RAGFlow | 直接接入 RAGFlow 知识库 |

## 3. 创建平台知识库

### 前置条件

- LakeSearch 服务已部署并可访问

### 首次配置默认知识库连接（新装环境必做）

新装环境首次创建平台知识库前，需先完成默认知识库连接配置：

1. 在"创建知识库"弹窗中，点击 **默认知识库配置**
2. 填写连接信息：
   - **服务地址**：LakeSearch 的访问地址
   - **鉴权方式**：
     - `basic`：HTTP Basic 认证，需在请求头中携带 Base64 编码的用户名:密码
     - `none`：无需认证，适用于内网无鉴权环境
   - **鉴权信息**：basic 模式下填写认证凭证（用户名:密码）
3. 点击 **测试连接**，确认提示"连接成功"
4. 点击 **确定** 保存

配置完成后，返回创建知识库弹窗，选择"默认"并点击"确定"，即可进入知识库创建页面。

> **界面提示说明：**
> - **"连接外部知识库"按钮**：当系统中没有任何第三方知识库连接时显示，用于引导用户接入外部知识库。一旦完成至少一个第三方知识库连接的配置，该按钮会自动隐藏。
> - **"默认知识库配置"按钮**：当默认知识库连接尚未配置时显示（即数据库中没有默认连接记录）。完成默认配置后，该按钮会自动隐藏。

### 操作步骤

1. 进入 **开发中心 > 组件库**，选择 **知识库** 页签
2. 点击 **创建知识库**，在弹窗中选择 **默认**，点击 **确定**
3. 填写基本信息：
   - 知识库名称（必填，1~50 字符）
   - 描述（选填，不超过 100 字符）
4. 配置模型：
   - 向量模型：用于文档向量化和语义检索
   - 精排模型：用于检索结果精细排序
5. 配置解析和拆分策略（可选）
6. 点击 **确定** 完成创建

### 上传文档

创建完成后可上传文档：
- **知识文档**：支持 docx、pdf、pptx、xlsx、txt、md 等格式，单文件最大 20MB
- **FAQ 问答对**：手动录入问题与答案
- **FAQ 文档**：按模板批量导入，支持 xlsx、docx 格式

## 4. 接入第三方知识库

### 4.1 General 知识库

适用于自研或非标准接口的知识库系统。

**接入步骤：**

1. 进入 **知识库** 页签，切换至 **外部知识库连接**
2. 点击 **连接外部知识库**，选择类型 **General**
3. 填写连接信息：
   - 知识库名称
   - 服务地址（需支持检索接口和列表接口）
   - 鉴权信息（HTTP Header 中的密钥）
4. 点击 **测试连接**，成功后保存
5. 返回 **知识库** 页签，点击 **创建知识库**，选择 **第三方**，勾选已连接的 General 知识库

**适配要求：** 第三方知识库需按接入规范提供检索和列表接口。

### 4.2 KooSearch 知识库

适用于已部署 KooSearch 服务的场景。

**接入步骤：**

1. 进入 **知识库** 页签，切换至 **外部知识库连接**
2. 点击 **连接外部知识库**，选择类型 **KooSearch**
3. 填写连接信息：
   - 知识库名称
   - 服务地址
   - 鉴权信息
4. 点击 **测试连接**，成功后保存
5. 返回 **知识库** 页签，点击 **创建知识库**，选择 **第三方**，勾选已连接的 KooSearch 知识库

### 4.3 RAGFlow 知识库

适用于已购买或部署 RAGFlow 的场景。

**接入步骤：**

1. 进入 **知识库** 页签，切换至 **外部知识库连接**
2. 点击 **连接外部知识库**，选择类型 **RAGFlow**
3. 填写连接信息：
   - 知识库名称
   - 服务地址
   - API Key
4. 点击 **测试连接**，成功后保存
5. 返回 **知识库** 页签，点击 **创建知识库**，选择 **第三方**，勾选已连接的 RAGFlow 知识库

## 6. 常见问题

### 6.1 点击"默认知识库配置"后无反应或报错

**检查步骤：**

1. 确认 LakeSearch 服务已部署且服务地址可访问
2. 检查 studio-manager 服务日志，搜索关键字：
   - `Fail to list models` — 模型查询接口调用失败
   - `Fail to get KnowledgeBase Connection Info` — 连接配置读取失败

**辅助排查 SQL：**

```sql
-- 检查默认连接配置是否存在
SELECT id, params FROM t_knowledge_base_connection
WHERE id = 'default_lakesearch_inside_connection_id';

-- 检查连接路由是否存在
SELECT * FROM t_kb_connection_router
WHERE knowledge_base_connection_id = 'default_lakesearch_inside_connection_id';
```

若查询结果为空，说明数据库初始化未完成。请检查：
- studio-manager 服务启动日志是否有数据库初始化相关报错
- 环境变量或配置文件中的数据库连接是否正确

### 6.2 创建知识库时向量模型/精排模型下拉框为空

**原因：** LakeSearch 服务中未注册模型。

**解决：** 确认 LakeSearch 服务已配置 embedding 和 rerank 模型。

### 6.3 配置完成后如何修改默认知识库配置

前端在配置完成后会隐藏入口，无直接修改界面。可通过 SQL 直接更新：

```sql
-- 查看当前配置
SELECT id, params FROM t_knowledge_base_connection
WHERE id = 'default_lakesearch_inside_connection_id';

-- 更新配置（params 为 JSON 格式，包含 endpoint、auth_mode、authorization 等字段）
UPDATE t_knowledge_base_connection
SET params = '{"endpoint":"新地址","auth_mode":"basic","authorization":"新凭证"}'
WHERE id = 'default_lakesearch_inside_connection_id';
```

修改后需刷新前端页面使配置生效。
