## 一、开发工具要求

| 服务 | 工具 | 版本要求 | 用途 | 版本检查 |
|------|------|----------|------|----------|
| studio-manager | JDK | 17+ | Java服务编译运行 | `java -version` |
| | Maven | 3.8.8+ | Java项目构建 | `mvn -version` |
| studio-runtime | Python | 3.11+ | 运行时引擎 | `python --version` |
| | uv | 最新版 | Python包管理（推荐） | `uv --version` |
| studio-console | Node.js | 22.12.0+ | 前端编译运行 | `node -v` |
| | pnpm | 7.0+ | 前端包管理 | `pnpm -v` |

> 各开发工具的安装配置请自行完成，本文档不在此赘述。

## 三、运行前准备

### 1. 下载源码

```bash
git clone https://gitcode.com/openJiuwen/agent-studio.git
```

### 2. 切换分支

进入 `agent-studio` 目录，切换到 `studio-2.0` 分支：

```bash
cd agent-studio
git checkout studio-2.0
```

### 3. 初始化数据库

登录数据库，执行以下语句创建数据库并授权：

> 数据库名可自定义（下方示例使用 `agent_studio`），JDBC 连接串中的数据库名必须与实际创建的数据库名一致。

**MySQL**：

```sql
CREATE DATABASE IF NOT EXISTS `agent_studio` CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
GRANT ALL PRIVILEGES ON `agent_studio`.* TO 'root'@'%' WITH GRANT OPTION;
FLUSH PRIVILEGES;
```

**GaussDB**：

> GaussDB 无需额外创建 schema，`DBCOMPATIBILITY = 'M'` 兼容 MySQL 语法，表结构由应用自动创建。GaussDB无需执行GRANT语句，使用安装时设置的超级用户即可访问。

```sql
CREATE DATABASE agent_studio TEMPLATE = templatem ENCODING 'UTF8' DBCOMPATIBILITY = 'M';
```

验证数据库创建成功：

**MySQL**：

```sql
SHOW DATABASES LIKE 'agent_studio';
```

**GaussDB**：

```sql
SELECT datname FROM pg_database WHERE datname = 'agent_studio';
```

> 主业务表由 studio-manager 首次启动时自动创建。

确认数据库时区：

```sql
-- MySQL
SELECT NOW(), @@time_zone;

-- GaussDB
SELECT NOW(), current_setting('TIMEZONE');
```

> 数据库时区需与部署环境一致，否则会导致定时任务执行时间偏差、数据记录时间戳不准确等问题。若时区不正确，可通过以下方式修改：
>
> - MySQL临时修改（重启失效）：`SET GLOBAL time_zone = '+8:00';`
> - MySQL永久修改：在MySQL配置文件 `my.cnf` 中添加 `default-time-zone = '+8:00'`
> - GaussDB修改：在 `postgresql.conf` 中添加 `timezone = 'Asia/Shanghai'`

### 4. 创建对象存储桶

在 OBS/MinIO 中创建桶，后续配置中的 `obs_bucket` 需填写此处创建的桶名。

**MinIO 示例**：

**方式一**：登录 MinIO 控制台（默认 `http://<MINIO_IP>:9001`），创建桶。

**方式二**：使用 mc 命令行：

```bash
# 添加MinIO服务别名，<MINIO_IP>、<ACCESS_KEY>、<SECRET_KEY>替换为实际值
mc alias set myminio http://<MINIO_IP>:9000 <ACCESS_KEY> <SECRET_KEY>
# 创建桶，agent-builder为示例桶名
mc mb myminio/agent-builder
```

## 四、编译与启动Java服务

### 1. 编译项目

启动 Java 服务前需先编译项目。后续修改 yml 配置无需重新编译，重启服务即可生效；修改 Java 源码后需重新执行以下命令：

```bash
cd backend
mvn clean install "-Dmaven.test.skip=true"
```

### 2. 配置必填项

studio-manager 的必填配置如下：

| 配置项 | 环境变量 | 说明 |
|--------|----------|------|
| `spring.datasource.url` | `spring_datasource_url` | 数据库JDBC连接串，格式参考下方说明 |
| `spring.datasource.username` | `spring_datasource_username` | 数据库用户名 |
| `spring.datasource.password` | `spring_datasource_password` | 数据库密码 |
| `spring.datasource.driver-class-name` | `spring_datasource_driver_class_name` | 数据库驱动，默认 `org.mariadb.jdbc.Driver`，GaussDB需改为 `com.huawei.opengauss.jdbc.Driver` |
| `redis.host` | `redis_host` | Redis地址，默认 `127.0.0.1` |
| `redis.password` | `redis_password` | Redis密码 |
| `redis.port` | `redis_port` | Redis端口，默认 `6379` |
| `obs.url` | `obs_url` | OBS/MinIO服务地址 |
| `obs.ak` | `obs_ak` | OBS Access Key |
| `obs.sk` | `obs_sk` | OBS Secret Key |
| `obs.bucket` | `obs_bucket` | OBS桶名 |

**服务间调用地址**（默认指向 `127.0.0.1`，本地启动无需修改）：

| 环境变量 | 说明 | 默认值 |
|----------|------|--------|
| `agent_runtime_endpoint` | studio-runtime 调用地址 | `http://127.0.0.1:31014` |
| `agent_builder_endpoint` | studio-builder 调用地址 | `http://127.0.0.1:31015` |
| `user_auth_endpoint` | 鉴权配置，Manager 默认调用自身 | `http://127.0.0.1:31111` |

> HTTPS启动时需将上述地址中的 `http` 改为 `https`。

> **SPRING_DATASOURCE_URL 格式**：
> - MySQL：`jdbc:mariadb://<MYSQL_IP>:3306/<DB_NAME>?allowMultiQueries=true`
> - GaussDB：`jdbc:opengauss://<HOST1>:8000,<HOST2>:8000,<HOST3>:8000/<DB_NAME>?targetServerType=master`

配置文件位置：

| 服务 | 配置文件 |
|------|----------|
| studio-manager | `backend/studio-manager-service/src/main/resources/application-manager.yml` |

### 3. HTTPS配置（可选）

本地启动默认HTTP，如需启用HTTPS，通过环境变量配置证书路径：

| 环境变量 | 说明 |
|----------|------|
| `server_ssl_enabled` | 设为 `true` |
| `CB_CF_SERVER_KEYSTORE` | server.keystore 证书文件路径 |
| `CB_CF_TRUST_KEYSTORE` | trust.keystore 证书文件路径 |
| `SERVER_SSL_KEY_STORE_PASSWORD` | keystore 密码 |
| `SERVER_SSL_TRUST_STORE_PASSWORD` | truststore 密码 |
| `SERVER_SSL_KEY_PASSWORD` | key 密码 |

### 4. 启动 studio-manager

> 需对 studio-manager 进行二次开发时推荐方式一，便于断点调试和热加载。若不修改本模块，仅调测，建议方式二。

**方式一：IntelliJ IDEA**

- 打开主类 `com.openjiuwen.studio.agent.manager.Application`
- 添加 Run Configuration：
  - Main class：`com.openjiuwen.studio.agent.manager.Application`
  - VM options：`-Dfile.encoding=UTF-8 -Dspring.profiles.active=manager`

**方式二：命令行**

```bash
cd backend
java "-Dfile.encoding=UTF-8" "-Dloader.path=studio-manager/target/lib/" -jar studio-manager/target/studio-manager-0.0.1.jar --spring.profiles.active=manager "--spring.config.additional-location=studio-manager-service/src/main/resources/"
```

默认端口 `31111`。

## 五、启动 studio-runtime

### 1. 配置环境变量

```bash
cd agent-runtime
cp .env.example .env
```

编辑 `.env` 文件，填写必填项，所有配置项的详细说明和默认值请参考 `.env.example` 中的注释。

> 如需启用HTTPS，在 `.env` 中设置 `HTTPS=true`，并配置 `TLS_CERT_PATH`、`TLS_CERT_KEY_PATH`、`TLS_CERT_KEY_PASSWD`。

### 2. 启动服务

```bash
uv run python agent_runtime/EIStart.py
```

默认端口 `31014`。

---

## 六、启动 studio-console

### 1. 安装依赖

```bash
cd frontend
pnpm install
```

### 2. 启动开发服务器

> 本地启动通过 `frontend/.staging/proxy.json` 配置代理转发。默认指向 `127.0.0.1`，无需修改。HTTPS启动时需将 `target` 中的 `http` 改为 `https`。

```bash
pnpm start
```

默认访问地址：`http://localhost:4200`
